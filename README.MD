# Computer Organization and Architecture Programs

## Experiment 1

1. Write a program to display "Hello World".
2. Write a program to add two 16-bit numbers.

## Experiment 2

1. Copy 10 words (16-bit numbers) from memory location `1000:0000` to `1000:2000`.
2. Copy 10 words (16-bit numbers) from memory location `1000:0000` to `2000:0000`.

## Experiment 3

1. Find the length of a string.
2. Check whether two strings are equal or not.
3. Check whether a string is a palindrome.
4. Reverse a string.

## Experiment 4

1. Implement Booth's multiplication algorithm.

## Experiment 5

1. Implement division using the Restoring Algorithm.
2. Implement division using the Non-Restoring Algorithm.

## Experiment 6

1. Implement Amdahl's Law and calculate speedup and efficiency for different numbers of processors.

## Experiment 7

1. Implement FIFO page replacement and calculate page faults, page hits, and the fault/hit ratio.
2. Implement LRU page replacement and calculate page faults, page hits, and the fault/hit ratio.

## Experiment 8

1. Compute the Block Index (BI), Cache Index (CI), and Tag Index (TI) for a direct-mapped cache.
2. Identify which main-memory block maps to each cache line.

## Experiment 10

1. Simulate a pipelined processor with stalls and calculate ideal and actual speedup and efficiency.
